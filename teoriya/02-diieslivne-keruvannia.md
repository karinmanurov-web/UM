# Урок 02. Дієслівне керування: як природно поєднувати слова

**Мета:** навчитися вживати поширені українські дієслова з правильними відмінками та прийменниками, не переносячи російські моделі керування.

## 1. Що таке дієслівне керування

Дієслово часто визначає, у якій формі має стояти залежне від нього слово. Наприклад, українською ми кажемо **допомагати кому?**, **цікавитися чим?**, **потребувати чого?**.

Тому корисно запам'ятовувати не окреме дієслово, а цілу модель:

- не просто *звикати*, а **звикати до чого?**;
- не просто *пишатися*, а **пишатися ким? чим?**;
- не просто *залежати*, а **залежати від кого? чого?**.

Схожі за значенням дієслова в українській і російській можуть вимагати різних відмінків або прийменників. Саме тут часто виникають кальки.

## 2. Дієслова, після яких потрібен родовий відмінок

| Модель | Приклад |
|---|---|
| потребувати чого? | Цей текст потребує уважного редагування. |
| уникати чого? | Я намагаюся уникати непотрібних суперечок. |
| позбутися чого? | Мені хочеться позбутися цієї звички. |
| досягати / досягти чого? | Вона прагне досягти своєї мети. |
| дотримуватися чого? | Важливо дотримуватися домовленостей. |
| прагнути чого? | Я прагну більшої самостійності. |
| набувати / набути чого? | З практикою людина набуває впевненості. |
| навчатися чого? | Вона навчається української мови. |

**Зверни увагу:**
- **потребувати допомоги**, а не *потребувати допомогу*;
- **досягти мети**, а не *досягти мету*;
- **дотримуватися правил**, а не *дотримуватися правила*;
- **позбутися страху**, а не *позбутися страх*.

## 3. Дієслова з давальним відмінком

| Модель | Приклад |
|---|---|
| допомагати кому? | Друзі допомагають мені з навчанням. |
| заважати кому? / чому? | Шум заважає мені зосередитися. |
| довіряти кому? | Я довіряю цій людині. |
| належати кому? | Ця книжка належить моїй сестрі. |
| подобатися кому? | Мені подобається українська вимова. |
| телефонувати кому? | Я зателефоную подрузі ввечері. |
| дякувати кому? за що? | Дякую тобі за підтримку. |
| радити кому? що робити? | Я порадила їй відпочити. |

У конструкціях із **подобатися** важливо не плутати того, кому щось подобається, і те, що подобається:

- **Мені** подобається ця книжка.
- **Їй** подобаються українські пісні.
- **Нам** сподобалася ця ідея.

## 4. Дієслова з орудним відмінком

| Модель | Приклад |
|---|---|
| цікавитися чим? | Я цікавлюся українською літературою. |
| пишатися ким? / чим? | Батьки пишаються донькою. |
| володіти чим? | Він добре володіє мовою. |
| керувати чим? | Вона керує невеликою командою. |
| захоплюватися ким? / чим? | Я захоплююся її роботами. |
| милуватися ким? / чим? | Ми милувалися вечірнім містом. |
| нехтувати чим? | Не варто нехтувати відпочинком. |
| опікуватися ким? / чим? | Вона опікується молодшим братом. |

Порівняй:
- **цікавитися музикою**;
- **захоплюватися музикою**;
- **мати інтерес до музики**.

Значення близькі, але граматичні моделі різні.

## 5. Дієслова з прийменниками

| Модель | Приклад |
|---|---|
| залежати від кого? / чого? | Результат залежить від обставин. |
| чекати на кого? / що? | Я чекаю на відповідь. |
| сподіватися на кого? / що? | Вона сподівається на підтримку. |
| розраховувати на кого? / що? | Я розраховую на власні сили. |
| звертатися до кого? / чого? | Звернися до викладача по допомогу. |
| звертатися з чим? | Він звернувся з проханням. |
| боротися з ким? / чим? | Вона бореться зі страхом. |
| погоджуватися з ким? / чим? | Я погоджуюся з твоєю думкою. |
| сперечатися з ким? про що? | Ми сперечалися з друзями про фільм. |
| вибачатися перед ким? за що? | Я вибачилася перед нею за запізнення. |
| дбати про кого? / що? | Важливо дбати про себе. |
| піклуватися про кого? / що? | Він піклується про батьків. |

**Не плутай:**
- **звернутися до людини** — адресуватися до неї;
- **звернутися по допомогу** — попросити допомоги;
- **звернутися з проханням** — прийти або написати з певним проханням.

## 6. Пари, у яких легко переплутати модель

### Потребувати — потребуватися

- **потребувати чого?**: *Ми потребуємо підтримки.*
- **бути потрібним кому?**: *Мені потрібна твоя порада.*

Не кажемо *я потребую підтримку* в нейтральній нормативній конструкції.

### Дякувати — подякувати

Обидва дієслова керують давальним відмінком особи та конструкцією **за що?**:

- *Дякую тобі за допомогу.*
- *Я подякувала викладачці за пояснення.*

### Навчати — навчатися — навчити

- **навчати кого? чого?**: *Викладач навчає студентів української мови.*
- **навчатися чого?**: *Студенти навчаються української мови.*
- **навчити кого? чого?**: *Вона навчила мене нових слів.*

У живому мовленні також природно: **вивчати українську**, **вчити слова**, **вчитися говорити**. Вибір залежить від змісту.

### Чекати — чекати на

Обидві конструкції нормативні, але вживаються не зовсім однаково:
- *чекати на автобус, на відповідь, на гостей*;
- *чекати слушної нагоди, чекати результатів*.

Не потрібно вважати прийменник **на** обов'язковим після кожного вживання слова *чекати*.

## 7. Як перевіряти себе

Коли сумніваєшся, постав питання від дієслова до залежного слова:

1. **Кого? чого?** — родовий: *потребувати часу, досягти мети*.
2. **Кому? чому?** — давальний: *допомогти подрузі, довіряти людині*.
3. **Ким? чим?** — орудний: *цікавитися історією, пишатися результатом*.
4. **На кого? на що? Від кого? від чого?** — перевір прийменник як частину моделі: *чекати на відповідь, залежати від обставин*.

Не покладайся лише на питання: найкраще запам'ятовувати дієслово разом із прикладом і типовою ситуацією.

| достигать цели | досягати мети / досягти мети |
| избавляться от привычки | позбуватися звички / позбутися звички |
| придерживаться правил | дотримуватися правил |
| доверять человеку | довіряти людині |
| мешать сосредоточиться | заважати зосередитися |
| интересоваться историей | цікавитися історією |
| гордиться результатом | пишатися результатом |
| управлять командой | керувати командою |
| ждать ответа | чекати на відповідь |
| зависеть от обстоятельств | залежати від обставин |
