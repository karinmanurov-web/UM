# Українська мова — UM

Персональний навчальний курс для переходу від упевненого розуміння української до вільного, природного й грамотного мовлення.

## Як користуватися курсом

- **Тут, у репозиторії:** теорія, приклади, тематичні словники та завдання.
- **У чаті:** відповіді на завдання, перевірка, пояснення помилок і звіти про прогрес.

Особисті відповіді, помилки та результати діагностики до навчальних матеріалів не додаються.

## Принцип курсу

Курс не починається з нуля. Основний акцент — активне мовлення, подолання буквальних перекладів і кальок, точне слововживання, природні словосполучення, керування та розширення активного словника.

Мета — сучасна, жива й нормативна українська, а не штучно ускладнена чи канцелярська мова.
